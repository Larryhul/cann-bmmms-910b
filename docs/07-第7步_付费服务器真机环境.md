## 手动进入与构建

```bash
source /usr/local/Ascend/cann-9.0.0/set_env.sh
cd /data/cann_bmm_20261015_v04/batchmatmulmaxsum_v04
export PYTHONPATH="$PWD/.python_deps${PYTHONPATH:+:$PYTHONPATH}"
cmake -S . -B build_cloud -DNPU_ARCH=dav-2201
cmake --build build_cloud -j4
```
